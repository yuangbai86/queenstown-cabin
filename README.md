# 再待一会儿 · 皇后镇湖边小屋

一个用来放空的小网页：坐在瓦卡蒂普湖边的木屋里，窗外是雪山，桌上有热咖啡。
场景插画和界面来自 Figma 文件「再待一会儿 · Queenstown Cabin UI」。

## 运行

- **最简单**：双击 `index.html`，用 Chrome / Edge / Safari / Firefox 打开。
- **推荐**（手机在同一 Wi-Fi 下也能访问）：在本文件夹里执行下面的命令，然后打开 <http://localhost:8000>。

  ```bash
  python3 -m http.server 8000
  ```

整个文件夹要放在一起，不能只拿 `index.html`。
字体 Noto Serif SC / Noto Sans SC 从 Google Fonts 加载，断网时会自动换成系统字体，其他功能不受影响。

## 文件结构

| 路径 | 内容 |
| --- | --- |
| `index.html` | 标牌、工具栏、各个面板（手账 / 相册 / 声音 / 使用提示 / 天气） |
| `style.css` | Figma 的颜色、字体、按钮、面板样式，以及动效和「减少动态效果」设置 |
| `app.js` | 场景叠加层、物品互动、天气与台灯、沉浸模式、手账与相册存储、合成环境音 |
| `assets/scene/desktop.webp`、`mobile.webp` | 网页实际使用的场景插画（已压缩） |
| `assets/scene/source/` | 你从 Figma 导出的原图（2 倍 PNG） |

屏幕宽高比小于 3:4（手机竖屏）时用手机构图，其余情况用电脑构图。

## 对应 Figma 的部分

- **配色**：cream `#FFF5E6`、paper `#FFFAF1`、ink `#493326`、sage `#78825E`、sageDark `#626D49`、border `#DDC8AE`、muted `#786A5D`、error `#A54436`（在 `style.css` 开头）。
- **布局**：左上角小屋标牌，右上角帮助按钮，底部居中工具栏（晴天 / 日落 / 雨天 + 声音 + 沉浸），最下面一行是小屋寄语。
- **手机**：工具栏变成「日落 ⌄」，点开是天气面板；所有面板从底部弹出。
- **手账**：空白 / 编辑 / 已收好 / 保存失败四种状态。
- **相册**：空白 / 网格 / 单张 / 删除确认四种状态。
- **沉浸模式**：隐藏所有控件，只留「退出沉浸」按钮，按 Esc 也能退出。
- **日落是插画本来的样子**。晴天和雨天在插画上叠加光线变化，天气切换用时 400 毫秒。

## 设计里没有、额外保留的

- **小植物彩蛋**（电脑构图）：点窗台上的植物，它会轻轻晃一下。手机插画里没有植物，所以手机上的彩蛋换成了「湖面」，点一下会泛起涟漪。
- **物品提示标签**：手机第一次打开时自动显示，也可以在帮助面板里随时打开或关闭。

## 数据保存在哪里

- 手账存在浏览器的 `localStorage`，照片存在 `IndexedDB`。
- **只保存在当前设备的当前浏览器里**，不会上传到任何地方。
- 照片保存前会缩小到最长边 1800 像素。

## 更换素材

### 换场景插画

**构图不变**（只是改了颜色或细节）：
- 把新图导出后替换 `assets/scene/desktop.webp` 和 `mobile.webp`。
- 也可以换成 PNG / JPG，然后把 `app.js` 里 `LAYOUTS.desktop.src`、`LAYOUTS.mobile.src` 的路径改成新文件名。

**构图变了**（物品挪了位置）：还要改 `app.js` 开头 `LAYOUTS` 里的坐标。
- 坐标单位：电脑图宽 2000，手机图宽 1125，和原图等比。
- `hot`：每个可点击物品的区域。
- `mug.d`：咖啡杯的轮廓，用来做「抬起」动画。
- `plant.d`：植物叶子的轮廓。
- `window`：窗户范围，雨丝和天气色调只画在这里面。
- `lamp.glow`：台灯光晕的中心。
- `steam`：热气的位置。
- `safe`：任何屏幕上都必须完整显示的区域。

### 换环境音

把可无缝循环的音频放进 `assets/`，在 `app.js` 开头的 `CONFIG.audio` 里填入路径：

```js
audio: { lake: 'assets/lake.mp3', rain: 'assets/rain.mp3' },
```

没有填的部分继续用浏览器实时合成的声音。

### 改文字

所有文案都在 `index.html` 里，可以直接修改，例如小屋寄语、面板标题、按钮文字。
咖啡、植物、湖面的小反馈句子在 `app.js` 的 `SIP_LINES`、`PLANT_LINES`、`LAKE_LINES` 里。
