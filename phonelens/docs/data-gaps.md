# 数据缺口与核验清单（待完成）

截至 2026-11-20，开发环境无法访问 apple.com.cn、mi.com、vivo.com.cn，因此**没有录入任何真实机型的参数、价格或评论**。目录中的真实机型只登记了型号和来源入口，参数全部显示“尚未核验”。

## 第一步：样板两款（必须人工完成）

- [ ] 确认候选机型的中国大陆在售状态、共同的 256GB 版本（参数页存在不能证明在售）。
- [ ] 按 `data/templates/specs_template.csv` 逐项抄录官网参数，每项记录来源编号和核验日期；官网未列出的填“官网未列出”。
- [ ] 按 `prices_template.csv` 记录价格，区分官方当前售价与建议零售价，补贴与换新条件单列。
- [ ] 在 `sources_template.csv` 登记每个来源的获取方式、允许保存与展示范围。
- [ ] 评论：先确定一个可以保存和展示的来源（用户授权反馈或明确许可的数据）。无法确认使用范围时不纳入公开数据，机型保持“仅参数”状态。
- [ ] 每款整理 30–50 条有效评论作为演示准备目标，实际数量如实显示。
- [ ] 运行 `npm run label-reviews` 生成标注草稿，人工抽查并填写 `reviewed_by` 后合并，提升 `label_version`。
- [ ] 运行 `npm run validate-data`：真实参数有数值但来源未标 `human_verified` 时会报错。
